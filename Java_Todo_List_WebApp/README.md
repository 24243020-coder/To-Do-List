# Java To-Do List Web Application

## Features
- Add tasks
- View all tasks
- Update/edit tasks
- Delete tasks
- Mark tasks as Done/Undo

## Requirements
- JDK 17+
- VS Code
- Maven (or Maven wrapper if added later)

## Run in VS Code
1. Extract the ZIP.
2. Open the `Java_Todo_List_WebApp` folder in VS Code.
3. Make sure JDK 17+ is installed.
4. Open VS Code Terminal.
5. Run: `mvn spring-boot:run`
6. Open: http://localhost:8080

## Note
Tasks are stored in memory, so they reset when the application is restarted.
